# TAKOVA

Repositório da **TAKOVA** — empresa moçambicana de tecnologia e serviços académicos
(Lichinga, Niassa). Contém dois produtos:

## 📁 `takova-website/`
Website institucional multi-página (HTML/CSS/JS estático, sem build). Serviços,
trabalhos científicos, sobre, contacto e a apresentação da app Somara.
→ ver [takova-website/README.md](takova-website/README.md)

## 📁 `somara-app/`
**Somara** — app didáctica gamificada (estilo Duolingo, percurso em amarelinha de
baixo para cima). Matemática e Português da 1ª classe, com o mascote **Roby** (o
mabeco), vidas, XP e progresso. Protótipo web jogável; base para a versão nativa
(Flutter/Android).

- Paleta: Chartreuse `#e1ff51` + Gun Metal `#00272c` + Verde Niassa `#2e8b57`.
- Correr localmente: `python -m http.server 8000` dentro de `somara-app/` (ou abrir `index.html`).

## 📁 `Features/`
Materiais de origem: mascote Roby (folhas), ícones, e o efeito de pirilampos.
Os manuais da 1ª classe (PDF) e o handoff de design **não** são versionados (ver `.gitignore`).
